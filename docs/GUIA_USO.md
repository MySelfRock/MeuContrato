# 📖 Guia de Uso - MeuContrato

## 🎯 Como usar o sistema

### 1. Criar uma conta

1. Acesse http://localhost:3000
2. Clique em "Criar Conta"
3. Preencha seus dados (nome, email e senha)
4. Você receberá 2 créditos gratuitos no plano FREE

### 2. Fazer login

1. Na página inicial, clique em "Entrar"
2. Digite seu email e senha
3. Você será redirecionado para o dashboard

### 3. Criar um contrato

#### Opção 1: Pelo Dashboard
1. No dashboard, clique em "Novo Contrato"
2. Navegue pelos templates disponíveis
3. Escolha o template desejado

#### Opção 2: Pela página de Templates
1. No menu superior, clique em "Templates"
2. Use a busca ou filtros por categoria
3. Clique em "Usar este template" no template desejado

### 4. Preencher o formulário

1. Você será direcionado para um formulário dinâmico
2. Preencha todos os campos obrigatórios (marcados com *)
3. Revise as informações
4. Clique em "Gerar Contrato"

**Atenção:** Esta ação consome 1 crédito (exceto plano BUSINESS)

### 5. Visualizar o contrato gerado

Após a geração:
1. Você verá o texto completo do contrato
2. Poderá copiar o texto
3. Terá acesso às suas respostas do formulário
4. Poderá gerar o PDF ou regerar o contrato

### 6. Gerar e baixar PDF

1. Na página do contrato, clique em "Gerar PDF"
2. Aguarde o processamento
3. Clique em "Baixar PDF" para fazer download
4. O PDF estará formatado profissionalmente

### 7. Gerenciar contratos

No menu "Meus Contratos":
- Veja todos os seus contratos
- Use a busca para encontrar contratos específicos
- Clique em um contrato para ver detalhes
- Delete contratos que não precisa mais

## 🎨 Status dos Contratos

- **Rascunho**: Contrato criado mas ainda não gerado
- **Gerado**: Contrato gerado pela IA e pronto para uso
- **Assinado**: Contrato assinado digitalmente (em breve)

## 📋 Templates Disponíveis

### 1. Contrato de Prestação de Serviços
Ideal para freelancers e prestadores de serviço

**Campos principais:**
- Dados do contratante e prestador
- Descrição dos serviços
- Valor e forma de pagamento
- Prazo de duração

### 2. Contrato de Aluguel Residencial
Para locação de imóveis residenciais

**Campos principais:**
- Dados do locador e locatário
- Endereço e descrição do imóvel
- Valor do aluguel
- Prazo do contrato

### 3. Termo de Confidencialidade (NDA)
Para proteção de informações confidenciais

**Campos principais:**
- Partes envolvidas
- Finalidade do compartilhamento
- Tipo de informação confidencial
- Prazo de confidencialidade

### 4. Contrato de Parceria Comercial
Para estabelecer parcerias entre empresas

**Campos principais:**
- Dados dos parceiros
- Objeto da parceria
- Responsabilidades de cada parte
- Divisão de receitas

### 5. Contrato de Compra e Venda
Para formalizar transações comerciais

**Campos principais:**
- Dados do vendedor e comprador
- Descrição do produto/bem
- Valor e condições de pagamento
- Condições de entrega

### 6. Contrato para Freelancer
Específico para trabalhos freelance

**Campos principais:**
- Dados do cliente e freelancer
- Descrição do projeto
- Entregas esperadas
- Valor e cronograma de pagamento

## ⚠️ Dicas Importantes

### Ao preencher o formulário:
- ✅ Seja específico e detalhado
- ✅ Use linguagem clara
- ✅ Revise todos os dados antes de gerar
- ✅ Mantenha documentos de suporte

### Sobre os contratos gerados:
- 📝 Sempre revise o contrato gerado
- 👨‍⚖️ Consulte um advogado para casos complexos
- 💾 Faça backup dos contratos importantes
- 🔄 Use a função "Regerar" se não ficou satisfeito

### Segurança:
- 🔒 Seus dados são criptografados
- 🔐 Nunca compartilhe sua senha
- 📧 Use um email válido para recuperação
- 🗑️ Delete contratos que não precisa mais

## ❓ Perguntas Frequentes

### Posso editar um contrato após gerar?
Atualmente, você pode:
- Copiar o texto e editar em um editor
- Regerar o contrato (consome crédito)
- Criar um novo contrato com informações diferentes

### Como funcionam os créditos?
- Cada geração de contrato consome 1 crédito
- Gerar PDF não consome créditos
- Regerar um contrato consome 1 crédito
- Plano BUSINESS tem créditos ilimitados

### Posso usar os contratos para fins comerciais?
Sim! Os contratos gerados são de sua propriedade e podem ser usados livremente. Recomendamos revisão jurídica para casos importantes.

### Os contratos são juridicamente válidos?
Os contratos são gerados com base em templates profissionais e IA treinada. Para máxima segurança, recomendamos consultar um advogado.

### Posso cancelar minha conta?
Sim, entre em contato conosco através do suporte.

A funcionalidade de upgrade estará disponível em breve.
